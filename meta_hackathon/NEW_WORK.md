# Portia: work done for the Meta Global AI Developer Hackathon

Everything below was built during the hackathon, in the order listed. Before it there was only the video database of
our playlist-eval paper (videos, questions, answer keys) and its segment index (Qwen3-VL-Embedding-8B vectors). The rules require newly developed work to be clearly identified,
and the demo shows only this work.
